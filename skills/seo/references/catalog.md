# SEO Skill Catalog

Source: github.com/every-app/open-seo — `plugins/openseo/skills/`. 12 skills, installed globally.

| Skill | Role |
|---|---|
| `seo-project-setup` | Establish project, site, market, baseline. Entry point for new clients. |
| `seo-audit` | On-page audit of what is broken now. |
| `keyword-research` | Find search demand and volume. |
| `keyword-clustering` | Group raw keywords into intent clusters — the unit of content work. |
| `competitor-analysis` | What competitors rank for that the site does not. |
| `competitive-landscape` | Wider SERP picture beyond named competitors. |
| `link-prospecting` | Where to obtain backlinks. |
| `ai-visibility-audit` | How the brand appears in AI answers (ChatGPT, Perplexity, AI Overviews). |
| `ai-prompt-research` | Which prompts surface competitors in AI engines. |
| `local-seo` | Local business / Maps / GBP. Only when relevant. |
| `seo-coach` | Turn findings into an ordered, prioritised plan. |
| `seo-report` | Client-facing deliverable. |

## Notes

- The repo is a pnpm monorepo (Vite, Drizzle, Cloudflare Wrangler). Only `plugins/openseo/skills`
  was installed — the app source, `pnpm-lock.yaml`, and deploy config were intentionally skipped.
- Traffic and volume numbers are third-party estimates. Always label them as such in client work.
